DATA STRUCTURES / ARRAY

배열 Array

연속된 공간에 데이터를 저장, 인덱스로 접근

인덱스로 원소에 접근

인덱스는 원소의 위치를 나타내며 0부터 시작

ARRAY VISUALIZATION
원소 수 4 / 용량 6
저장된 원소빈칸
저장된 원소 0–3 · 용량 범위 0–5 · 범위 밖 인덱스도 입력 가능

현재 동작arr = [12, 24, 36, 48]

인덱스를 입력하면 해당 위치의 원소를 강조

자동 진행
접근 O(1)

인덱스로 위치를 계산해 바로 접근

고정 용량 6칸의 배열 예시 · 삽입과 삭제는 원소의 순서를 유지하는 방식
미사용 슬롯은 null, 용량 밖 접근은 Index out of bounds로 표현한 학습용 모델 · 실제 결과는 언어와 자료형에 따라 다름
