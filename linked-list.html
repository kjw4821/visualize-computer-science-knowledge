DATA STRUCTURES / LINKED LIST

연결 리스트 Linked List

각 노드가 다음 노드를 가리키며 연결

HEAD부터 next를 따라 순차 탐색

노드는 데이터와 다음 노드의 참조로 구성 · 마지막 노드의 next는 null

위치는 0부터 시작 · 순서를 세기 위한 번호
SINGLY LINKED LIST
노드 수 4화살표는 next 참조 · 노드 ID는 메모리 주소가 아닌 식별자

현재 동작head → 12 → 24 → 36 → 48 → null

위치 설정 후 시작

자동 진행
탐색 O(n)

HEAD에서 시작해 원하는 위치까지 next를 따라 이동

단일 연결 리스트 예시 · 화면의 노드 간격은 실제 메모리 배치와 무관
초기화 또는 탭 전환 시 미완료 연산 취소 · 완료된 연산은 다음 조작에 유지
