트리 Tree

부모와 자식 관계로 데이터를 계층적으로 연결

루트 Root부모가 없는 시작 노드
부모 · 자식간선으로 이어진 위·아래 노드
리프 Leaf자식이 없는 끝 노드

조작 예시 · 이진 탐색 트리 BST — 각 노드에서 왼쪽 서브트리의 값은 더 작고 오른쪽은 더 큰 구조

루트부터 값을 비교하며 탐색

작으면 왼쪽, 크면 오른쪽 자식으로 이동 · 일치하거나 null에 도달할 때까지 비교

BINARY SEARCH TREE
노드 수 7루트 40 · 리프 4개 · 높이 2
입력 값 -999–999 · 정수

현재 동작root = 40

연산 시작 후 2초 간격 자동 진행 · 좌우 버튼으로 단계 이동 가능

자동 진행
탐색 O(h)

트리 높이 h에 비례 · 균형이 좋으면 O(log n), 편향되면 O(n)

일반 트리는 값의 대소 정렬 규칙이 없음 · 이 화면의 연산은 이진 탐색 트리 기준
중복 값은 삽입하지 않음 · 학습용 최대 노드 수 15개 · 자동 균형 조정 없음
높이는 루트부터 가장 깊은 리프까지의 간선 수 · 빈 트리 높이는 -1로 표시
초기화 또는 탭 전환 시 미완료 연산 취소 · 완료된 연산은 다음 조작에 유지
